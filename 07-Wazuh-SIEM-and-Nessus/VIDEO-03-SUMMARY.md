# Video 3 — Quick Project Summary

**Project:** Building a virtual security operations and vulnerability-assessment lab using Proxmox, pfSense, Wazuh, Docker and Nessus.

**Outcome:** Configured Wazuh monitoring for Kali and Ubuntu, enabled Ubuntu Docker listener, investigated pfSense agent monitoring and permissions, deployed Nessus Essentials, and repaired a blocked Nessus plugin setup caused by a full 19 GB Ubuntu root filesystem. Expanded the root LV online to 38 GB with 19 GB free. Completed Nessus scan results remain pending.

**Resume-ready project bullets (edit to fit your resume):**

- Deployed a Wazuh SIEM lab on Proxmox VE and monitored Kali Linux and Ubuntu systems through centrally managed security agents.
- Diagnosed Linux service, syslog, and agent permission issues using `journalctl`, `systemctl`, access-control changes, and structured configuration checks.
- Installed Nessus Essentials and resolved a plugin initialization issue by expanding an Ubuntu LVM/ext4 root filesystem from 19 GB to 38 GB without reinstalling the VM.
