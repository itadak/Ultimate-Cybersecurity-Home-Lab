# Ultimate Cybersecurity Home Lab

## Project Overview
This project documents my hands-on experience building a virtual cybersecurity home lab. The goal is to develop practical skills in network security, threat detection, vulnerability management, and security monitoring.

I am using this project to strengthen my technical knowledge and prepare for cybersecurity roles, including Security Operations Center (SOC) Analyst and Cybersecurity Analyst positions.

**Project Status:** In Progress

## Project Objectives
- Build and configure a virtual cybersecurity environment.
- Learn how to secure and monitor a network.
- Practice identifying security threats and vulnerabilities.
- Gain hands-on experience with cybersecurity tools.
- Document technical configurations, troubleshooting, and results.

## Planned Technologies
- **Kali Linux:** Security testing and analysis.
- **pfSense:** Firewall configuration and network security.
- **Wazuh:** Security monitoring and threat detection.
- **Nessus:** Vulnerability scanning and assessment.
- **Virtualization:** Creating and managing virtual machines.

*This list will be updated as tools are installed and configured.*

## Lab Documentation
Each completed stage will include:
1. Objective and tools used.
2. Installation and configuration steps.
3. Screenshots of the lab environment.
4. Problems encountered and solutions.
5. Results and skills learned.
